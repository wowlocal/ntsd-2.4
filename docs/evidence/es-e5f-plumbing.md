## 2. Could the engine read them from data the game already ships?

The 151 rectangles: no (`.text` immediates; not in `initial.bin`, which is
`.data`). Interface, menu, war and common-sound names: yes in substance (they
equal the entry order of manifests the content identity pins, and the engine
checks it). Front (24) and menu-sound (5) names: no (the startup manifest is
sorted by path; the load order cannot be recovered). Recommendation: profile
lists for all six, the manifest checks kept (same check, same error). About
2.4 KB of `Int32` and 70 ASCII strings; `OriginalGameRules.==` returns early on
shared storage (`OriginalGameRules.swift:635`).

## 3. Plumbing

In `OriginalGameRules` (the catalog's rules already reach
`OriginalCharacterScreen.swift:62`). A public family `Interface`:
`frontBitmaps`, `frontSheets: [OriginalBitmapSheet]` (ordered; frames
`{x, y, width, height: Int32}`), `interfaceBitmaps`, `menuBitmaps`,
`warBitmaps`, `commonSounds`, `menuSounds`; preconditions: counts 24/10/11/2/18/5
(the engine's slot tables), every sheet slot among the first 11 front slots
(replacing a `firstIndex(of:)!` trap), at most 500 frames a sheet, ASCII names
without NUL. The front menu runs before the catalog: the startup path needs
the rules: `OriginalApplicationStartupInputs.rules` (from the identity, kept by
`replacingFile`) → `OriginalMacRuntimeStartup.run` (:97) →
`OriginalApplicationWindowStartup.init`, `OriginalApplicationObservedStartup.init`
→ `OriginalApplicationHostSession.start` → `OriginalApplicationBootstrap.start(…rules:…)`
→ `Session.State.rules` (replacing `front: .init()` at
`OriginalApplicationBootstrap.swift:158`). Only NTSDRuntime among the hosts
(two files). NTSD's values in `native/Sources/NTSDProfile`, the generator's
output with them.

## 5. Risks and decisions

Write order (sheets, frames, x/y/width/height, the count after the frames,
the null-bitmap exit between sheets): an array, not a dictionary; the
reference corpus catches deviations. ENDING keeps `first(where:)` and its
error. Names are emitted as UTF-8 and compared with captured C strings: ASCII,
backslashes kept. wasm32: slots below 2³¹, no new `Int(UInt32)`. Two routes
for the same rules (startup, catalog) match by construction in the app (no
guard; the review notes it). `OriginalContentIdentity.swift:4-7`'s doc (names
stay the engine's) changes. Frozen records untouched
(`build/research/*-export-pins.json`, `tools/loading_*_candidate/`,
`tools/OriginalStartupAudioMenuCorpus.swift`).

**For the user:** the E7 policy and D1 (the music tracks and labels,
`MENU_BACK` and its count, the built-in background names, EXE strings, the VC80
table; D1 would also show which counts are NTSD edits [I]: CLIP2–7, CS2–6).
The loop can settle E5f-1 to E5f-4.
