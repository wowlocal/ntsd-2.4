One run executes97 returned parents (90 overlapping prefixes/10 references and
seven returned call-00 parents), then nine rejected invocations:106 total.
It compares7844 front events,38 music events,202 graphics events and all214
ordered checkpoints:45 outer,63 War,74 preparation and32 numeric. Numeric points
are included in214. All saved pre-guard checkpoint groups must be consumed.
The five pre-War outer checkpoints retain own entry Actors and BGs; independent
review verified all45 such source joins. The32 release/free API globals compare
to the own43a3b1 checkpoint, with no intervening global change established by
saved evidence and Core review; this is an anchor, not a new post-guard snapshot.

Acceptance requires the exact OriginalStateError.invalidStorage message.
A different error, XCTest unwrap or Stop.unexpected cannot establish a Native
boundary. Full rollback checks own globals, World, Actors, BGs, bitmap storage
and release ownership/order, War scratch, resource contexts, music and recording
buffers, library state and committed events against declared entry state.
Expected source fault after-state never supplies that rollback target.

Saved fault publication omits nested startup/output reports. The test preserves
that absence and compares five saved early checkpoints at their actual Native
entry/afterMusic/resourceCheckpoint/afterStartup stages. It requires retained
menu202, loadflag0 and selection3; any startup request without its absent report
fails as a harness error. Explicit unused Native output-response slots carry no
source semantics: the exact Native guard must occur before output is reached.
