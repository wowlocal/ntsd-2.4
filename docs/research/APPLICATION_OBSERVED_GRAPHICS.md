## Contract and implementation

This follows [installed text replies](APPLICATION_TEXT_RESPONSES.md),
[observed bitmap service](APPLICATION_OBSERVED_BITMAP.md), and the whole
[menu session](APPLICATION_MENU_SESSION.md)/[bootstrap](APPLICATION_BOOTSTRAP.md).
It reads preserved EXE/DLL evidence and source corpora. No original code,
Unicorn, historical source producer or Windows test executes in this increment.

`OriginalMenuGraphicsRequest` distinguishes Window, bitmap-with-stage and
front-with-stage requests. Replies preserve the corresponding complete response.
Front replies carry signed results and optional outputs. Nonnegative GetDC
requires an explicit output, including zero; negative GetDC may omit output,
skips subsequent text calls and preserves the library's prior DC. Other numeric
GDI failures remain returned values. String length and internal observations
are not external requests.

`OriginalApplicationObservedGraphicsIteration` reuses the existing
`OriginalRequestExchange` algorithm. Host surface, lifecycle, bitmap and front
providers consume the same staged cursor. A request becomes serviceable only
after the whole Core/Host attempt unwinds. Publication requires consumption of
the complete journal and the captured Host sequence. Receipts and resource
owners survive retry; physical IO is not rolled back. Earlier nonempty journals
remain retained through copied platform snapshots and delayed delivery contexts.

MenuSession emits one `frontAPI` effect with the actual reply. Graphics ownership
consumes that effect once. Original text events remain observable without
emitting a duplicate effect. Surface Release updates the bitmap owner with its
actual result. Presentation's actual result reaches the World-return checkpoint;
the dispatcher's own return remains separately 1. Prepared routes and their old
effect vocabulary remain available. Observed surface requests reject mixed
prepared response arrays, matching the existing bitmap/lifecycle boundaries.

The Mac bitmap service gains an overload for the common journal. Its device
preparation, validation, execution and failure body remain unchanged. The shared
exchange source also remains byte-identical to the preceding candidate. Author
checks record these facts; they are not independent review.
