# Преобразование клавиш сетевого меню

Целый helper `422f60..423222/ret` перенесён в
[OriginalMenuCharacter](../../native/Sources/NTSDCore/OriginalMenuCharacter.swift).
Все10492 контролируемых вызова совпадают по потребляемому caller байту AL и
порядку чтений Shift/запросов GetKeyState. Это первая зависимость
[полного сетевого меню](NETWORK_MENU_PLAN.md), ещё без300-key обхода и изменения
hostname. Критерии были заданы в [MENU_CHARACTER_PLAN](MENU_CHARACTER_PLAN.md).

## Эталон и граница

Исполняются инструкции pinned `NTSD 2.4.exe` SHA256
`3f7ac67c5890ef979ee24a6dae5528056e7f631725c292cf9cb0a928ebeff71c`
после настоящего установщика bundled lib.dll, SHA256
`28d4f1b07992e058840bdac04d8ba44d6f037a248e29d962712bf44bcf90baba`.
Среда — Unicorn2.1.4, CW023f; ответы GetKeyState заданы явно. Это не Windows,
раскладка macOS, измерение клавиатуры или полный CRT startup. Дизассемблирование
и hooks нужны для восстановления необычных проверок AX, повторных запросов и
сохранения порядка чтений. API граница не исполняет Windows keyboard driver.

Родительский lib installer воспроизводится полностью. Перед каждым вызовом
глобальные46144 байта восстановлены из PE/installer и объявленного Shift input.
После вызова все байты те же, маска записей нулевая. Проверены484142848 байт,
сохранённые регистры, SP2000f004, CW023f и настоящий возврат. Source сохраняет
полный EAX; независимый verifier восстанавливает также его старшие байты.
Нативный API возвращает UInt8: caller428371 исполняет `movsx ecx,al`, не читая
старшие байты EAX. Эквивалентность частного ABI этим не заявляется.

## Правила

Пробел32, keypad96..105 и операторы107/109/106/111/110 возвращают соответственно
пробел, цифры и `+ - * / .`, не читая Shift и Caps Lock. Диапазоны key проверяются
как UInt32 с исходным unsigned wrap. Любые прочие ключи читают byte455388,
включая неизвестные и навигационные; только точное значение100 означает Shift.

Буквы65..90 сначала читают Shift. При100 следует GetKeyState(20): нулевой AX
сразу даёт заглавную. В остальных случаях следует отдельный GetKeyState(20).
Его signed low16<=0 даёт строчную; положительный результат вызывает повторное
чтение Shift, где100 даёт строчную, любое другое значение — заглавную. Поэтому
два последовательных ответа API нельзя объединять. High16 результата не влияет
на выбор символа. Native получает live Shift через throwing provider при каждом
исходном чтении.

| Ключи | Без Shift100 | С Shift100 |
| --- | --- | --- |
| 48..57 | `0123456789` | `)!@#$%^&*(` |
| 189,187,219,221,186 | `- = [ ] ;` | `_ + { } :` |
| 222,220,188,190,191,192 | apostrophe, backslash, comma, period, slash, grave | quote, vertical bar, less-than, greater-than, question mark, tilde |

Навигационные33/34/35/36/37/38/39/40/12/45 дают `9/3/1/7/4/8/6/2/5/0` при
обоих значениях Shift. Остальные ключи дают NUL. Получены все96 различных
результатов:95 printable ASCII и NUL.

## Покрытие и отказ

9000 случаев покрывают каждый caller key0..299, пять Shift bytes и шесть
signed Caps Lock значений. Ещё936 — все36 пар последовательных Caps ответов
для26 букв,512 — каждый Shift byte для буквы/цифры,40 — unsigned range controls,
4 — API high-word controls. Всего11048 Shift reads,2890 keyboard requests и
13938 упорядоченных событий.8516 вызовов не требуют API,1062 требуют один,
914 — два. Глобальных записей и исходных memory faults нет.

Исполнены305 из318 starts,0 DLL PCs внутри decoder. Недостающие13 starts
422ff6..42301e — повторный буквенный блок: неизменный EBX уже не прошёл тот же
unsigned диапазон65..90. Это статически недостижимый блок, не динамическое
покрытие. Общая lowercase-инструкция423020 исполняется другим путём.

Неизвестный обязательный Shift и отсутствующий первый/второй API response
отклоняются. Пробел/keypad не требуют непрочитанных данных. Сам helper не
меняет native state; enclosing menu должен стадировать своё изменение строки
и буферизовать внешние эффекты до общего commit. Искусственного повреждения
управляющих полей, cookie или исходных аварий в этом исследовании нет.

## Текущее приложение и оставшаяся работа

Изолированный NTSDNative запущен с существующими game.json/Assets. Сохранены
живое состояние Practice и встроенный AppKit/SpriteKit захват1588×1200
`build/research/menu-character-app-render.png`: District, оба бойца и HUD видны.
Процесс захвата завершился0. Инструмент CUA не смог запустить канал связи:
`Sky Computer Use native pipe startup failed`. UI-действий не было; первый
живой процесс остановлен SIGTERM только после проверки его PID/команды, exit-15.
Это техническая недоступность UI-инструмента, не safety refusal и не штатное
закрытие первого окна. Подробности и hashes сохранены рядом в app JSON/logs.

Этот захват подтверждает запуск и рендер нынешнего Practice, к которому новый
decoder не подключён. Управление, задержка, анимация во времени, слышимый звук
и Windows fidelity здесь не подтверждены. Следом нужны полные network menu1/2/3,
собственное происхождение hostname, библиотечный text route, output/epilogue,
listener/peer joins. CRT/NLS, остальные lib hooks, приложение общего движка,
полный матч, весь игровой объём и clean-Mac проверка остаются открытыми.
