## A material lifetime distinction

The audio corpus executes in the same controlled CPU and caller stack, but its
adapter resets `w.regions` on each 4014e0 entry. `platform()` reuses FIRST27000020
and SECOND28000020 for each call, retaining that call's results separately.
Read-only AST inspection and all 400 saved controls confirm this behavior.

The 666 recorded PCM regions contain 115,045 cross-call overlapping range pairs.
They are not 666 simultaneously live allocations, a source memory fault or
measured Windows heap/device behavior. Distinct buffer tokens do not establish
persistent distinct mappings for the reused PCM scratch. Blindly transplanting
these controls into the owned application's persistent range journal would
contradict its declared storage contract.

The next Native study must define new logical bindings against actual retained
startup/common/game regions, preserve separate PCM values and buffer identities,
and compare relocated fields explicitly. The old controls, expected bytes and
masks remain immutable. This is a declared new Native environment, not recovery
of unknown original mappings or authorization to change an expected result.

## What the full fixtures do not establish

Their observed file/image order and complete game records do not contain the full
bitmap COM/DC response sequence, actual resource generations, loading animation
globals or clock/message sequence of the current application chain. The audio
fixture separately preserves whole WAV calls. It does not fill those caller gaps.

The next implementation should use the existing shared handlers with a resource
and control provider that owns each attempt. Original DAT/WAV/image bytes are
available from the existing self-contained fixtures. Declared platform replies
and logical identities must remain separate from comparison-only records. Compare
all full catalog records, masks, allocation/registration order and retained owners;
exercise cancellation after a late child and immediately before publication.
Retain the three complete twenty-child application comparisons as regressions.

A complete Native pass in that declared environment can establish a real owned
catalog return and rollback contract. Full original application comparison,
