## Required evidence and limits

Before execution freeze the256-entry manifest, producer, pinned inputs and
finite expected counts. Retain atomic cases only after each call terminates;
stream final assembly and keep the6GiB storage reserve. Never restart completed
preflight/setup/catalog jobs or a live job merely because its log is quiet.
A source fault stops the affected call; preserve it without continuing its
corrupted state. A safeguard refusal stops automatic retries of that operation.

Audit complete before/after bytes/masks, every checkpoint/read/store/helper,
exact instruction bytes and all40 reproduced parent calls (20 two-call pairs). Track each
source constructor parent separately; repeated reproduction is not a count of
new unique startup states. Assert each400-byte activation clear precedes the
team pass, every active slot is derived from the declared status vector, CPU
uses seat+10 while human uses seat, Object/team/controller/multiplier/MP and
intermediate numeric stores agree, and56 complete recordings retain allocation
and replacement/free ownership. Check actual chosen arenas and RNG streams.

Compare every Release/free pair and fresh allocation at its actual position,
including old recording replacement. Reuse device identifiers only according
to the declared allocator/COM model; never reset counters over live resources.
All Native state and external effects must remain staged through the outer
return. Add source-coupled late release/free rollback trials when those events
first become available; preserve the earlier12 first-preparation rollback trials.
